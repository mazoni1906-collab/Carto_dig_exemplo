Dados geográficos de Minas Gerais

Visualizador das camadas de hidrografia, malha rodoviária e limite estadual fornecidas com este projeto. Os dados são apresentados no sistema de referência SIRGAS 2000 (EPSG:4674).

Para agilizar a navegação, o mapa utiliza cópias simplificadas dos GeoJSON. Os arquivos originais podem ser baixados na seção de cada camada.
